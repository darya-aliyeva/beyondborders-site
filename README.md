# Beyond Borders · dance academy concept

Landing page for **Beyond Borders**, a fictional dance academy for teens 12-17 in Düsseldorf. Portfolio project: concept, texts, design (Figma) and hand-written front-end.

The studio, people, address and contacts are invented. Forms send nothing.

- Plain HTML, CSS and JavaScript, no build step
- Motion: GSAP + SplitText (self-hosted in `js/vendor`)
- Self-hosted fonts, no cookies, no trackers
- Sample legal pages: `impressum.html`, `datenschutz.html`, `einwilligung.html`
